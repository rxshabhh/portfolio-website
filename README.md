# Personal Portfolio

A modern, interactive portfolio built to showcase my projects, technical skills, and experience through an engaging and responsive web experience.

## Features

* Modern and responsive UI
* Smooth animations powered by GSAP
* Interactive 3D character using React Three Fiber
* Project showcase with detailed descriptions
* Competitive programming highlights
* Mobile-friendly design
* Built with Vite for fast performance

## Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* GSAP
* React Three Fiber
* Framer Motion

## Getting Started

Clone the repository:

```bash
git clone https://github.com/<your-username>/<your-repository>.git
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```
